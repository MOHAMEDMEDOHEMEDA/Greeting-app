# Greetings App 👋🌍

A cross-platform Apple application built with **SwiftUI 6** that runs seamlessly on **iOS, iPadOS, and macOS**.

The app provides multilingual greeting experiences with adaptive **Dark & Light Mode**, smooth animations, and interactive gestures while following modern Apple design principles.

This project was developed as part of the **Deep Dive iOS 26 & SwiftUI 6: 90-Hour Project-Based Course** to strengthen advanced SwiftUI and cross-platform development skills.

---

## ✨ Features

- 🌍 Multilingual support
- 🌙 Dark & Light Mode support
- 📱 Works on iPhone, iPad, and macOS
- 👆 Interactive gestures and animations
- 🎨 Modern SwiftUI user interface
- ⚡ Smooth and responsive performance
- 🧩 Reusable SwiftUI components
- 🔄 Real-time UI updates with SwiftUI state management
- 🖥️ Adaptive layouts for different Apple platforms
